# P1：VAD 后端 A/B 实验数据方案（2026-11-20）

> 目的：回答「要不要为 KikuSub 换一个轻量 VAD 切分器」，而不是先改产品。
> 本方案冻结在跑数之前；跑完把数字追加到文末，再决定是否进设置页。
> 红线：不打开窗口、不改既有评测基线、同一区间同一 ASR 参数，只换 VAD。

## 1. 候选组

| 组 | 后端 | 参数 | 角色 |
| --- | --- | --- | --- |
| V0 | Silero 20s 窗 | 0.25 / 80 / 200 / 250ms | 现状基线 |
| V1 | Silero 10s 窗 | 同 V0 | 零依赖召回上限 |
| V2 | TEN-VAD | 0.45 起，再扫 0.35 / 0.55 | 最干净的替换候选 |
| V3 | WhisperSeg | 0.35，再扫 0.25 | 最对症的轻声候选 |
| V4 | FireRedVAD | 0.40 / 0.30 | **只做纸面对照，不跑** |

后端通过 `KIKUSUB_VAD_BACKEND` 选择（`silero` / `silero10` / `ten` / `whisperseg`），
A/B 阶段不进 `core/params.py`、不进设置页；胜者才接 UI。

## 2. 固定项

- 素材：`../Jap_test_2.mp4`（918.06s）为主，`../Jap_test.mp4`（830.23s）做复现；
  参考字幕 `Jap_test_2_perfect.srt` / `Jap_test_perfect.srt`。
- 引擎：Anime Whisper 为主（P1 决策口径），Qwen 只做交叉核对。
- ASR 参数、`enable_loudnorm`、`merge_vad_segments`、`extend_segment_onsets` 全部沿用
  当前产品默认；VAD 原始输出先映射成统一 `stamps`（样本下标），后处理完全同源。
- 区间：全片；另取最长无参考字幕的 60s 窗口做负样本（纯 BGM/环境音代理）。
- 解释器：`../.venv/bin/python`；跑前用 `--check-fixtures` 核对指纹。

## 3. 指标

`score_srt.py`（同区间）：
CER、`missed_blocks`、`insertions`、`max_cue_dur`、`over_4_3s`、`particle_start_cues`、
`aux_start_cues`；`run_clip.py`：`onset_missing`、条数、耗时、峰值 RSS/MPS。

VAD 侧新增（评测脚本，不改产品）：
- **参考条覆盖率**：参考字幕每条时间窗被 VAD 语音段覆盖 ≥90% 算命中；
- **低能量参考条覆盖率**：按参考条内 RMS 取最低 20%，看轻声/耳语是否被切到；
- **负样本段数/语音占比**：60s 无台词窗口内 VAD 段数，越低越好（不是 0 也可以，
  后处理会过滤，但越少越省）。

## 4. 判据（不达标不换默认）

1. CER 不劣化超过 +0.3pt；
2. 至少一个 fixture 的 `missed_blocks` 相对下降 ≥20%，另一个不上升；
3. `insertions` 上升 ≤10%，负样本段数不高于 V0 的 1.5 倍；
4. `max_cue_dur` / `over_4_3s` 不恶化；
5. `onset_missing` 不上升；
6. 耗时增加 ≤20%，峰值内存不超过现有 ASR 峰值；
7. 打包后 30s 转写能跑通（TEN 验 dylib 签名；WhisperSeg 验 ONNX + 权重路径）。

只允许一个胜者进产品；不达标就记录「不换」，保留环境变量实验开关。

```bash

  --media ../Jap_test_2.mp4 --ref ../Jap_test_2_perfect.srt --fixtures .. \

```

### 6.3 决策

- **TEN-VAD：拒绝。** 负样本 97.9% 判成语音，整片 CER 从 15.48% 涨到 61.01%、插入 505；
  它不是「更灵敏」，而是把 BGM 当人声。不接产品，A/B 开关保留在 `core.vad` 里。
- **Silero 10s：拒绝作为默认。** 覆盖率和句首缺字变好，但 CER +2.41pt、插入 +35、
  耗时 +25%；零依赖也不能抵消回归。
- **WhisperSeg：正式接入为可选切分器，不做默认。** 它把 CER 降 4.8pt、插入降 29%、
  耗时降 55%，且参考条/低能量条 100% 覆盖、负样本 0 误报；但 `missed_blocks`
  没下降（13 条是 ASR 识别问题，不是 VAD 没切到），最长条 3.82s→4.70s、
  >4.3s 0→6，没有通过「最长条/超长条不恶化」这条判据。
- **默认仍 Silero 20s。** 需要优先降 CER/插入/耗时的用户，可在参数面板把
  「VAD 切分器」切到 `whisperseg`；首次使用自动下载约 114MB 权重。
  注意：VAD 自身耗时 10.6s vs 2.9s（+7.7s），但送模段数 67 vs 156，
  端到端反而从 127.5s 降到 57.1s；判据 6 按端到端口径算通过。
- **只对 Whisper 开放该设置。** Qwen 用同一后端 CER 反而 +1.14pt、漏块 +1，
  说明 WhisperSeg 的长块切分与 Qwen 的 CTC/断句不匹配；Qwen 继续用 Silero。
- 后续若要把它升为默认，先解决长条：按 6s 强制切分能把 >4.3s 从 6 条降到 4 条，
  但 CER 略升 0.11pt，需再做一轮「切分上限 × CER」的标定。
