### P3 后续：人声绝对能量门控（2026-11-21）

- 现象：`vad_only` 下 Demucs 的 vocals 在纯音乐/环境段并不是绝对零，WhisperSeg 会把
  -76～-85 dBFS 的串音判成语音；`dynaudnorm` 再把底噪抬起来，ASR 于是产出
  「ちゅぅ…」这类幻觉字幕（dpmx-014 片头 27.6s / 40.1s / 64.2s）。
- 为什么没有让 VAD 直接听 raw：实测把 VAD 参考换成 `enable_loudnorm=False` 后，
  言叶之庭 40:10–41:10 歌曲段 `vad_only` CER **21.32% → 25.74%**（插入 7→10），
  违反红线 4。最终**保留 dynaudnorm 做检测**，另解一份未归一化的 vocals 电平，
  只给门控用——检测边界与 CER 都不动。
- 实现：`core/vad.py` 的 `VOCAL_GATE_DBFS = -65.0` 与 `gate_stamps_by_energy()`；
  Whisper / Qwen / Sherpa 三条引擎在 VAD 之后、clamp/merge 之前门控；
  `load_wav_mono(peak_gain_out=…)` 用于还原峰值归一化增益（否则 -85 dBFS 的段会被
  放大 85 倍后看起来是 -50，门控失效）。
- 标定（dpmx-014，2h48m）：幻觉段 -76～-85 dBFS，真实对白中位 -33.8 dBFS；
  -65 丢 57/1101 段（128.5s），-60 会误删 -60.3 dBFS 的轻声句。
- A/B：两个评测区间 `vad_only` 的 CER / 漏块 / 插入与基线逐项一致
  （21.32% / 7.76%），ASR 16k wav sha256 相同，门控丢弃 0 段。
- 全片：VAD 1079→1022 段；对现有 1282 条主稿逐条门控只删 **6 条（0.47%）**。

### 归因勘误（2026-11-22 复核）

这一节把「时间轴紧贴说话声」的功劳重新记到正确的地方，避免后来者以为
`use_prev_text_prompt` 会动时间轴。

- **「时间轴紧贴发声」来自 Silero 的 20s 分窗机制，与 `use_prev_text_prompt` 无关**。
  `_decode_chunk(..., prompt_text=...)` 只往 `generate_kwargs` 里塞 `prompt_ids`，
  `seg_start_s / seg_end_s` 一行都没动。紧贴感由三处既有机制共同产生：
  `core/vad.py::_silero_detect`（20s 窗 + 1s 重叠、跨窗区间并集）、
  `merge_vad_segments`（`merge_gap_s=0.3` / `max_segment_s=9.0` + 能量低谷吸附）、
  `core/timing_repair.py`（保留 end、只把 start 右收）。
  本片实测（100ms RMS 包络，字幕起点相对参考起点的平均绝对偏差）：
  Silero 0.25 **0.23s**（P90 0.71s）vs WhisperSeg 0.35 **0.68s**（P90 1.47s）；
  段内静音占比 Silero **4.5%** vs WhisperSeg **12.4%**（-60dBFS、前后 200ms 缓冲口径，
  与下表「静音」列同一算法）。
- **上一句提示的收益只在 CER，不在时间轴**：Silero 打开提示后段内静音
  **4.5% → 4.5% 完全不变**、最长条 4.22s 也不变，只有文本改（CER 15.49% → 11.55%）。
  把它写成「切得更紧」是错的，已在 §「结论」与 `params-and-presets.md` 更正。

### 漂移定位与修复（2026-11-22，已重跑验证）

- **根因**：`_refine_bounds_by_pauses()` 直接逐帧调 `vad(...)` 求概率曲线，
  而 Silero 是**带隐藏状态的 RNN**，库里的 `get_speech_timestamps` 会自己
  `reset_states()`，这条旁路不会——同一段音频的首帧概率会继承上一次调用的状态。
  已在探针前补一行 `vad.reset_states()`，并加回归测试
  `tests/test_core.py::test_refine_bounds_resets_stateful_vad_before_probing`。
- **修复后已重跑整片**（2026-11-22，两轮独立进程）：Silero 关提示 15.49%、
  开提示 11.55%，90 条，两轮逐条一致（仅 1 处句尾差 32ms），与最早九组连跑的
  D1/D2 对得上。`runs3/` 的 17.46/13.80（88 条）由此判定为漂移产物。
- **90 条 vs 88 条的差异记录**（`runs/D2p` 90 条 → `runs3/V2_silero_on` 88 条）：
  ① 96.20–103.05 处旧版 3 条（`早くボクの` / `コトイジメテぇー` / `可愛がってぇー`）
  并成新版 2 条（`早くボクのことイジメテェー` / `かわいがってぇ…`）；
  ② 306.90 的 `んっ` 在新版消失（旧版有、新版无）。
  其余 0.1–0.3s 的边界差值都是同一处解码差异的连带结果，不是新的切分规则。
- 影响面：只在「句首/句尾发声被剔除」的段上生效，量级 ~0.1s；已在重跑中体现，
  表中 D1/D2p 两行即修复后的数字。

结论（都已落成参数/预设/门控，不是「再讨论」）：

- **阈值 0.45 是唯一在两份素材上都不劣于基线的档**。本片 0.35 是拐点（18.59%）；
  0.25 与 0.45 在 CER 上打平（同为 12.11%，两边编辑数都是 43、构成不同），但块准确率
  65.4% → 75.7%、漏块 9 → 5、条数 100 → 96。对话动画 `Jap_test_2`（918s、79 条 / 872 字、
  `outputs/eval/asmr-gate/`）上更直接：0.25 = **10.78%**（插入 74）→ 0.45 = **7.68%**
  （插入 42），块均 77.6% → 79.2%。默认值 0.25 → 0.45。
- **上一句提示只对 Silero 有效**（**15.49% → 11.55%**，含 `reset_states()` 修复后两次独立重跑一致），
  WhisperSeg 上反而 12.11% → 26.76%
  （四格同进程对照，`runs3/`）；因此 `backend_only="silero"`，代码门是
  `prev_text_prompt_enabled()`。护栏（长停顿 >3s / 可疑幻觉 / 装饰符 / 复读）仍保留，
  实测在这条素材上不触发或只用掉 1 次，不影响数字。
- **人声分离送 ASR 仍是否决项**（3 处修复 / 3 处新错）；分离只用于 VAD 时对无 BGM 素材
  几乎无收益（0.39pt），保持默认只服务 VAD。
- **双引擎复核：专名差异靠「低相似度短语高亮」浮出来（2026-11-22 已落地）**。
  Qwen 副稿确实把 `魔族` / `クレイドル` / `みっちりプラン` 听对，本片实测 58 条
  diff（`build_review` 现算，非历史引用值），其中含名词 14 条。
  早先的问题是**发现成本**：两处最该被看见的差异恰恰拿不到高亮——
  `CHAR_HIGHLIGHT_MIN_RATIO = 0.35` 在 `だーてん` vs `当店、魔族`（0.000）上
  整行不着色、只留一个 `~`，`マゾックレイドル…` vs `クレイドル…`（0.867）才着色。
  现在是：低相似度行改用 `phraseOps()` 做**短语级标记**（相邻同类片段合并后整段
  标 del/ins，不做最短长度过滤），加「整句不同」标记与红框对照，
  并提供「按差异大小排」（先低相似度 diff、再其它 diff、最后 `only_*`）。
  标记文案只写「整句不同」：它的用途是让人**快速定位到两个模型完全不一致的句子**，
  再自己去判断是不是专名听错；写「看彩色片段」是在解释实现，反而分散注意力。
  「一键采纳副稿文本」本来就有（`adoptAltText()`，`cec498c`），按钮只在 `diff` 行，
  低相似度行也带，现在从「排序 + 标记」两头都能直达。
  取证：`tools/shots/verify_dual_lowdiff.mjs`（11 项断言，真实 Whisper/Qwen 稿）。
  仍未做的是**「专名」这一层语义识别**：它认的是「相似度低」，不是「这是个名字」；
  真正按名词表挑出来要接词表或 NER，不在这一轮。
  `ensemble` 补漏对这对仍是 **0 条**——它只收「副稿有、主稿时间不重叠」的行，
  名词差异天然与主稿重叠（`PRIMARY_OVERLAP_RATIO=0.20` 直接筛掉），这是设计而非缺陷。
- **正式预设**：「日语 ASMR：轻声耳语·Silero 切分」= Silero 0.25 + 上一句提示 +
  默认其余参数，配合**关闭人声分离**使用。
