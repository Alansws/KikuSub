## 1. T1 · 200% 缩放与窄宽降级（P0）

### 改法
- 断点只加媒体查询，未改桌面结构：
  - `desktop/renderer/src/app.css`：`@media (max-width: 900px)` 侧栏 236 → 56（品牌文字、分组标签、计数收起，图标居中）。
  - `components/Toolbar.svelte`：≤900 隐藏副标、`AI 优化 / 导出` 只留图标（title/aria-label 保留）、间距收紧；≤760 隐藏引擎分段与标题后的分隔线。
  - `components/Inspector.svelte`：≤900 由占列改为 `position:absolute` 右侧抽屉，`width: min(348px, 92vw)`、`z-index:20`、`transform: translateX(103%)` 收起、180ms 只动 transform。
  - `App.svelte`：`matchMedia('(max-width: 900px)')` 进入紧凑模式时把抽屉收起一次并记下宽屏值，回到宽屏再还回去；抽屉打开时工作区加半透明遮罩（120ms 淡入），Esc 先收抽屉。
  - `lib/store.svelte.ts`：新增 `app.compact`；`setView / openMedia` 在紧凑模式不再自动打开检查器（仅「右键添加字幕」仍强制打开，因为要把光标放进文本框）。
  - `views/ReviewView.svelte`：≤900 整屏纵向滚动、stage/timeline 左右 16、表格保底 200px；播放器宽度 `min(640px, 100%, calc((100vh - 170px) * 16 / 9))`，让「视频 + 播放行 + 工具行」正好占满首屏（否则 680 宽下播放条会被推到首屏之外）；≤700 表格降为 `30px 78px minmax(0,1fr) 36px` 并隐藏「结束 / 时长」两列。
  - `views/TranscribeView.svelte`：≤900 双栏改单栏（680 下右栏只剩约 200px，标签会竖排、控件被裁）。
  - `components/QaPanel.svelte`：≤900 面板铺满工作区宽度、`z-index:18`，压在抽屉（20）之下。

### 紧凑模式的交互验证
- 抽屉：工具栏开关打开 → 遮罩出现 → Esc 收起（`open1:true, open2:false, scrimAfter:false`）→ 点遮罩收起 → 切到导出再回核对，抽屉保持收起（不回弹）。
- 查找栏：680 下压成一行（`.find-bar` 高 39，表格仍有 148px）；540 下折成两行（高 70，表格 99px，仍 ≥90）。隐藏了「Aa」与分隔线，输入框可收缩。
- 图标可读性：侧栏图标轨与工具栏「AI 优化 / 导出」在收起文字后补了 `aria-label`（title 仍在）。

### 已知限制
- 680×419 下一屏放不下「视频 + 波形 + 表格」三块（数学上不可能同时满足视频 ≥300 与表格 ≥90），所以核对台在紧凑模式是可滚动的：首屏是画面与播放/时间轴工具，表格在下一屏。
- 宽屏 ↔ 紧凑的「恢复上一次宽屏值」只能在真实改窗口大小时触发；截图模式无法改窗口尺寸，这条是代码审查 + 桌面/紧凑两套截图分别验证的，没有做动态 resize 录像。

## 3. T3 · 表格 / 时间线细节（P1）

- **当前句完整**：1360 / 1440 / 200% 680 下分别量第 1、2 行 `.line` 的 `scrollWidth / clientWidth` = 341/341、407/407、396/396，无省略号（列宽未动）。540（1080 窗口的 200%）只剩 256px 文本列，长句会省略——这是 4 列 + 极端缩放的预期，不追求完整。
- **行内动作热区**：视觉仍 19px，伪元素 `inset: -2.5px -2px` 把命中区撑到 23×24；按钮间距 2 → 4，热区之间仍留 1px。行高不变。
- **双语行**：固定 60px，两条 20/16 + gap 2，长译文两行内省略（`nowrap + ellipsis`），不会撑破行。
- **数值对齐**：行号 / 时间码 / 时长全部 mono + `tabular-nums`；表头与单元格共用同一 grid 列宽，实测左缘 312/412（1360）与 312/418（1440）完全一致。
- **字幕轨道 `LANE_H`**：保持 17。放大到 200% 后是 34 设备像素、可点；100% 下 17px 也可拖，而改动它必须同步 `laneTopOf()`、绘制与命中三处，收益不抵风险。`wave-resize`（6px）与 lane 不重叠，实测未变。

- **抽屉遮挡画面**：按规划抽屉是覆盖层、不参与布局（挤压会把视频压到 244×137，更差）。缩放下关闭抽屉（× / Esc / 遮罩）即可看全画面；这条作为已知取舍保留。
- **表格行高 35–36 / 40**：实测两种宽度都是 **30px**；评审量的是 4x DPR 预览里的设备像素。
- **吸顶顶栏切断控件行**：截图是滚到表格处时的滚动位置，顶栏在滚动容器之外，没有被吸顶。
- **行尾动作列补表头**：桌面同样留空表头，行尾动作不承担列语义。
- **删掉检查器「参数 / 输出」重复数字**：这是检查器的输出摘要，属于 P1 既有设计，不在本轮「200%/行高/动效/文案」的改动面里。
- **设置页 960 宽、长行、词序、「打包运行：否（源码模式）」**：属于 P0 页框与诊断信息；「内存建议 16 GB」在 `core/engines.py`，改它要重打 sidecar，本轮只记录。
- **设置页隐藏撤销/重做/历史**：`AGENTS.md` §3.4.2 要求全局撤销对所有视图可见（导出设置也要能 ⌘Z），不能隐藏。
- **「更新此行」像禁用**：未改动时它本来就是禁用态（中性灰），有改动时是实心 accent；P1 评审已确认过这条语法。
