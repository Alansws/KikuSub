## 第三批调整（按反馈，2026-11-12 00:01）

1. **删掉「跟随中」右侧残留提示**：`ReviewView` 的 `.tl-hint` 标记与样式已删；「跟随中」用 `.tl-follow { margin-left:auto }` 固定在控制行右端。截图 `review.png` 已重取。
2. **双 Dock/双 Electron 修复**：复现时 `lsappinfo` 显示两个 `Electron` 应用条目，各自带不同的 `--user-data-dir`——Electron 的单实例锁跟着 userData 走，所以不同 profile 会真的并存。
   - 开发模式现在把 userData 固定到仓库 `.dev-userdata/`（已 gitignore），并在 `requestSingleInstanceLock()` 之前设置；第二次启动会退出并聚焦第一个窗口。
   - `--screenshot` 取证模式自动跳过这条；确实要并行调试时设 `KIKUSUB_ALLOW_MULTIPLE=1`。
   - 实测：两个不同 `--user-data-dir` 启动，只剩一个主进程。
3. **应用图标**：从上传图左上角裁出蓝色 K → `docs/app-icon.png`（1024 透明底，macOS 留白 + 阴影）→ `desktop/build/icon.icns`；开发模式 `app.dock.setIcon(build/icon.png)`，打包脚本 `build_app.sh` 优先用 `docs/app-icon.png`；现有 `build/pack/KikuSub.app` 的 icns 也已替换。
