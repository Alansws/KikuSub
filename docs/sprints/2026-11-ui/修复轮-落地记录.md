# KikuSub · 四个问题的修复记录（2026-11-12）

> 范围：状态栏引擎、核对台字幕来源与右侧信息、状态栏日志路径、质检面板 UI / 呼出动效。
> 设计沿用已确认的 D「青空」令牌，只做组件级深化，不另开方向。

## 1. 修复内容

### 1.1 状态栏引擎跟随顶部切换
- `StatusBar.svelte` 原来把引擎写死为 `whisper`，现改为由 `App.svelte` 传入当前 `engine`，
  再按 `app.config.engines` 查 label。
- 顶栏切到 Qwen3 后，状态栏同步显示 `Qwen3-ASR + CTC`；切回 Whisper 显示 `Anime Whisper`。

### 1.2 导入字幕后右侧不再显示上一次转写的信息
- 新增 `Session.review_source`：`transcription` / `import` / `draft`，随字幕快照返回，
  并随 20 步历史一起回滚（导入后 ⌘Z 会同时恢复上一版字幕与来源）。
- 整片 / 追加转写写入 `transcription`；导入字幕写 `import`；恢复草稿写 `draft`。
  单句 / 选区重转保留原来源（它不重写整片质检队列）。
- `GET /api/qa` 在 `import` / `draft` 时返回 `detached: true` 的空态；
  `POST /api/qa/action` 返回 409，避免旧 item 删错句、补错区间。
- 检查器：`import` / `draft` 时隐藏「质检速览 / 生效参数」，显示「当前字幕」来源、
  文件名、条数与说明；「输出」改用当前来源的文件名。
- `ReportView` 增加提示条：当前核对台已换字幕后，这份报告只属于上一次转写。
- 导入字幕时顺带丢弃条数已对不上的旧译文轨，避免「新字幕配旧译文」。

### 1.3 状态栏日志路径
- 删除右下角的 `outputs/logs/kikusub.log` 文本；日志仍可在「设置 → 日志与诊断」查看。

### 1.4 质检面板 UI 与呼出动效
- **信息层级**：头部改为「图标 + 质检待核 + 已核对/待核摘要 + 下一条/刷新/收起」；
  3px 进度条；筛选拆成两层——分组用分段控件（漏检 / 低置信 / 全部），
  状态用下划线 tab（待核 / 已核 / 全部），避免两组「全部」长得一样。
- **列表**：每条一个 `article`，左侧复选框 + 类型胶囊 + 等宽时间码 + 时长 + 文本；
  主操作（补录 / 保留 / 恢复原句）实心或淡蓝，跳过靠右收成次级动作；
  完成项降透明度并显示勾选结果。
- **空态**：统一 40px 图标、标题、说明；覆盖/切片统计胶囊居中。
  新增「当前字幕不是这次转写的结果」专用空态：说明来源、提供「去转写并生成质检」。
  没有可用条目时隐藏进度条与筛选，减少无意义控件。
- **动效**：面板 220ms 弹出（10px 上移 + 0.985→1 轻微放大），130ms 收起；
  进度条 260ms；条目 180ms 淡入；系统开启「减少动态效果」时全部为 0。
- 面板内按 Esc 收起（App 全局键盘）；状态栏质检按钮仍保留当前 tab 的待核数。
