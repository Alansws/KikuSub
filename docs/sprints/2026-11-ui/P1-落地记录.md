# KikuSub · P1 落地记录（2026-11-12）

> 方向：**D「青空」已确认**。本轮把 D 从设计稿落到真实产品：核对台重排、全局令牌与蓝色 accent 统一、P3 的 AI 空态 / 提示词卡 / 文案 / 动效、图标重生成。
> 证据截图：`shots/`。构建：`cd desktop && npm run build` 通过。

## 0. 一句话结论

核对台现在是 D 的骨架：640×360 画面落在纸面上，顶栏只留「AI 优化 / 导出 / ⋯」，时间线拆成播放行 + 工具行，表格 30px 行高、选中行淡蓝底 + 2px 蓝左线，右侧当前句 20/600 白卡。全站 accent 从系统蓝 `#007aff` 换成 `#4F6BFF`，深色换成中性墨底 + `#7D93FF`。原有交互契约全部保留并回归通过。

## 1. 决策与假设（用户没逐条拍板的，按“改得回来”处理）

| 事项 | 处理 | 理由 |
| --- | --- | --- |
| 主按钮颜色 | 仍用 accent 蓝（D 稿里是墨色） | 任务明确要求“把蓝色 accent 统一到其他页”；墨色主按钮会变成第二套强调语法 |
| 深色变体 | 补了：`#0A0C10 / #111419 / #181C23` + accent `#7D93FF` | 产品本来就有外观切换，不能只有浅色 |
| 侧栏品牌标 | 用户后来确认：**换成 `docs/app-icon.png`**（renderer 里放 128px 资源，20px 显示，圆角 5） | 与 Dock/打包图标一致；D 稿也是它 |
| 视频尺寸 | 640×360、圆角 10、只留阴影；窗口更窄时等比缩小 | D 稿数值；窄窗口（最小 1080）不横向溢出 |
| 检查器宽度 | 320 → **348** | D 的三栏 236 / 1fr / 348 |
| 波形默认高度 | 148 → **80**，仍可拖把手调整并记忆 | D 的波形比例；给表格腾出 6 行 |
| 工具栏高度 | 修正为 **52**（原来 CSS 写了 52/44 两个值，实际生效 44） | 与 P0 记录、设计规划一致 |
| 表格行高 | 26 → **30**（双语 60） | D；`ROW_H` 与虚拟列表同步 |
| 主题色语义 | `--bg-content` 改为 raise（卡片/输入/浮层），页面底单独用 `--paper` | 旧变量名保留为别名，页面不用一次性重写 |

## 2. 改了什么

### 2.1 令牌（`desktop/renderer/src/app.css`）
- D 的浅色 palette 原样写入：`--canvas #EDF3FB`、`--paper #F9FBFE`、`--raise #FFF`、`--ink #1B2740`、`--ink-2 #5A6780`、`--ink-3 #68758A`、`--line(.12) / --line-2(.06)`、`--accent #4F6BFF`、`--accent-soft(.08)`、`--accent-line(.35)`。
- 深色：`#0A0C10 / #111419 / #181C23`，accent `#7D93FF`，侧栏 0.92 不透明（沿用 P0 的 vibrancy 处理）。
- 旧变量（`--text / --bg-content / --separator / --cue-*`…）映射到新值；`.btn` 改白底发丝边、`.btn.ghost` 去边框、`.card` 用 raise、焦点环 `:focus-visible` 统一、滚动条/状态点/芯片改语义色。
- 新增 `--font-sans / --font-mono`、`--dur-*`、`--shadow-video`。

### 2.2 顶栏（`components/Toolbar.svelte`）
- 仅核对台显示：`AI 优化`、`导出` 文字按钮；`⋯` 菜单收「压制代理 / 导入字幕」（带状态与禁用说明）。
- 撤销 / 重做 / 历史 / 外观 / 检查器保持原位置；「⋯」有分组分隔线、菜单有 140ms 入场。
- 导入字幕动作从 `ReviewView` 移到 `store.importSubtitleFromExport()`，顶栏与旧入口共用一份。

### 2.3 核对台（`views/ReviewView.svelte`）
- 结构：`.stage`（视频 + 播放行 + 工具行）→ `.timeline`（波形）→ `.table-area`，左右 26px 与 D 对齐。
- 播放行：24px 圆形播放键、12px mono 时间码、3px 轨道 + 9px accent 描边旋钮、时长。
- 工具行：`− / 滑杆 / + / 1.0×`、`全景`、`聚焦`、行末 `跟随中` 胶囊（带 5px 点）。
- 选区工具条仍浮在工具行上（不推挤波形）；窄窗口隐藏时间范围、只留时长，避免挤出右边界。
- 表格：30px 行高 / 双语 60、15px 字幕、`accent-soft + inset 2px` 选中、18px 底部渐隐、窄窗口列宽收窄（≤1220px）。
- 波形：默认 80px、刻度文字 12px mono、已播放段用 accent 重绘（60%）、右端标签不再被画布裁掉；canvas 只在尺寸变化时重设位图（播放时重绘不重新分配）。
- 删掉旧 `.tl-hint`（P0 已删）与 TTS 下的说明句；空表提示收成一句。

### 2.4 检查器（`components/Inspector.svelte`）
- 348px；内容独立滚动、保存 dock 固定在底部（不再随滚动消失）。
- 当前句：白卡 + 2px 蓝左线，时间码 12 mono，正文 20/600（译文 16/400）；双语两种框都可编辑。
- 动作区：`试听 / 聚焦 / 删除(图标) / 更新此行(主)`。
- TTS 收成一行：`TTS 对照 / 本机 · 离线` + 朗读 + 音色 + 语速。
- 生效参数 / 输出改用 D 的 section（发丝线上分隔，不再套 card），保存 dock 保留暂存 + 轨道 + 格式 + 导出。

### 2.5 其他页
- 全局 accent 现在是 `#4F6BFF`（深色 `#7D93FF`），导入 / 转写 / 导出 / 设置 / 提示词 / AI / 报告都走令牌；只剩状态色（warn/green/red）保持语义。
- 清理了硬编码蓝：`QaPanel` 的 `rgba(10,132,255,.14)`、`ReviewView` 选区 `rgba(0,122,255,.13)`、`ExportView` 渐变 `#7aa2ff`。
- 原生 `range / checkbox / radio / progress` 统一 `accent-color: var(--accent)`，系统蓝不再混进转写/导出/AI 页的勾选框与滑杆。
- 页框全部保留 `PageHeader` 与 720/960/1120 宽度。

### 2.6 P3
- **AI 空态**：不再把“还没有提案文件”当红色错误顶在首屏；工具条在无提案时只留空态里的「生成提案」主按钮 + 「导入提案…」次按钮，有提案才出现 生成 / 导入 / 重新加载 / 另存 / 丢弃 / 应用 分组。
- **提示词卡**：`展开全文 / 收起` 替代 9 行硬裁；折叠 216px + 26px 渐隐，展开 420px 内滚；标题 15、正文 13/1.7；删掉底部路径说明。
- **文案**：导入页的 MKV/HEVC 说明收成一行（细节进 tooltip）、转写「调小更灵敏…」进 tooltip、导出重复说明删除、设置页删「后端注册引擎」段落与 transformers 版本（`core/engines.py` 的 notes 同步）。
- **动效**：页面切换 280ms 淡入 + 4px 上移、toast 180ms、历史/更多菜单 140–160ms、选区条 140ms 淡入、保存 dock 吸底；全部受 `prefers-reduced-motion` 约束。

### 2.7 图标与开发工具
- 由 `docs/app-icon.png`（1024 透明底）重跑 `make_icon.swift` → `icon.icns`；`desktop/build/icon.png`（dev Dock 用）从 4096²/16MB 换成 1024/510KB；`build/pack/KikuSub.app/Contents/Resources/icon.icns` 同步替换。
- 侧栏品牌标换成应用图标：`desktop/renderer/src/assets/app-icon.png`（128px，25KB）+ `Sidebar.svelte` 的 `<img>`；Vite 打进 `dist/assets`。
- `main.cjs` 新增三个 dev-only 开关：`KIKUSUB_WIN_SIZE=1440x900` 覆盖窗口尺寸；`KIKUSUB_ZOOM=2` 做 200% 页面缩放取证；截图前把指针移到 (2,2)，避免真实鼠标悬停把某一行染成 hover 底色。
- 打包已重打并验证：sidecar 724MB、`KikuSub.app` 979MB，带新 UI 启动成功（截图 `shots/packaged-review.png`）。

## 5. 独立视觉评审与修正

盲评（不给代码与过程，只给当前截图 + 方向约束）结论：**8/10**。点名 4 处核心缺口 + 1 处他页裁切，已按影响改完：

| 评审问题 | 处理 |
| --- | --- |
| 时间线缩放控件太弱（1px 灰线 + 空心圆，读不出倍率） | 改成填充式滑块：已选段实心 accent、实心拇指，−/+ 换成图标按钮；100% 时整条填充 |
| 块条 11/12 都用蓝，稀释强调色 | 非当前块改中性墨（亮 `rgba(27,39,64,.14)` / 暗 `rgba(236,241,250,.12)`），只有当前块用 accent；选中区间底纹也改中性 |
| 1360 默认视口当前句被截 | ≤1400px 列宽 94/94/54/42、文本右内边距 6；当前句在 1360 完整显示 |
| 「更新此行」禁用态像浅紫大块、状态不可辨 | 禁用主按钮退成中性灰（`--fill` + `--ink-3`），启用时才实心 accent |
| 保存区四个控件同权重、无下拉感、两个「导出」重名 | 下拉恢复原生 chevron、宽度收到 54；按钮改名「导出字幕」；总宽 307/307 不溢出 |
| 提示词卡末行被渐隐切穿 | 收起态改 `-webkit-line-clamp: 9`（整行 + 省略号），展开态 420px 内滚 |
| 波形已播放/未播放明度太接近 | 未播放改浅灰 `#A3ADBE`、已播放 accent 提到 90% 不透明，明度差拉开 |
| 垃圾桶离主动作太近 | 增加 4–6px 间距 |

**未采纳**（有明确理由，写在这里避免下次反复）：
- 设置页正文左边缘比别的页多约 40px：因为设置页是 P0 锁定的 720 单栏居中，属于页框而不是意外。
- AI 页 / 报告页没有 22px 的 `PageHeader` h1：AI 页的顶栏就是它的工作头，报告页用 `转录任务详报` 的印刷式小节；加页头会额外占掉工具高度。若用户要求统一，再单独做。
- 让块条承担 scrub：属于交互扩展，不在本轮“按 D 落地”的范围。
