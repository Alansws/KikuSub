## 1. P1-2 非对白短幻觉：时间戳复核 + 疑似标记

### 1.1 实现

`transcribe.py` 新增 `hallucination_risk()`：

- 病理性复读（去标点后连续单元 ≥6）：`じゅるっ、じゅるっ…`；
- 短段（<1.2s）且至少 2 字：正常短句在时间戳模式下会保留，噪声段通常解成「…」；
- 长段但字数密度极低（<0.8 字/秒）：例如 8 秒只出 3 字。

命中后用 Whisper 的 `return_timestamps=True` 再解一次：

- 复核结果为空/纯标点 → **丢弃**，计入 `hallucination_drops`；
- 复核仍有文本 → **保留但标为疑似**，计入 `suspect_cues`，报告里提示人工核对；
- 复核本身异常 → 保留原结果，写 debug 日志。

报告新增：

```
【幻觉门控】已丢弃 N 段经时间戳复核为空的疑似幻觉
【幻觉复核】N 段短/低密度结果未被丢弃，建议人工核对
```

### 1.2 实测

60–66s（雨/环境声，参考字幕无台词）：

- 旧行为：`…信じる` / `…新撃…` 类假字幕；
- 新行为：短段被标为疑似（`suspect_cues=1`），报告提示人工核对；病理复读段若复核为空会直接丢弃；
- 有声段（38–48s 对白）不受影响。

### 1.3 边界

Whisper 的时间戳模式本身也可能幻觉（实测 0.75s 的 `…新撃…` 在两种模式下都存在），所以本轮是**降噪 + 标记**，不是“100% 消灭幻觉”。真正按置信度过滤需要拿 `avg_logprob/no_speech_prob`；当前 transformers Whisper 的 `generate` 没有把 scores 暴露给 pipeline，硬改会动到推理主链路，留作后续。

## 5. P2-6 编解码兼容提示

- 新增 `_probe_video_codec()`：ffprobe 读取首个视频流 `codec_name`，按路径+体积+mtime 缓存；payload 增加 `codec`。
- 播放器加载后：
  - 只有 **真的没有画面/报错**（`video.error` 或 `videoWidth===0`）才显示提示；
  - 不再用 `canPlayType` 判断——实测 Chromium 对 HEVC 返回空字符串但系统解码器实际能播，会造成误报；
  - 视频开始播放后自动隐藏提示。
- 提示文案：“浏览器未能解码 HEVC 视频；画面若黑屏，请点左侧「⚡ 压制 480p 代理」”。
- 实测：HEVC 测试片段正常播放时**不再**误报；旧版会误显示。
